# BlastiX Esports Hub

Admin hub for the **BlastiX** esports platform — the central web interface where administrators manage tournaments, teams, players, matches, and content.

## Overview

This repository will host the **BlastiX Esports Hub** website: the admin-facing dashboard used to run the competitive side of the BlastiX ecosystem. It gives organizers a single place to set up events, track results, and keep the platform's data up to date.

> ⚙️ **Status:** Early setup. The project is being scaffolded — features and stack below describe the planned build.

## Planned Features

- **Tournament management** — create events, build brackets, and schedule rounds
- **Teams & players** — register, edit, and organize rosters
- **Match scheduling & results** — record scores and update standings
- **Leaderboards & rankings** — live standings across events
- **Users & roles** — manage admins, moderators, and permissions
- **News & announcements** — publish content to the platform
- **Analytics** — overview of activity, participation, and performance
